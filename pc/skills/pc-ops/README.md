# pc-ops: maintenance skills for this PC

Written fresh in the shape HomelabHero gives its operator skills (triage
first, read-only vitals, then one skill per job), for one Linux Mint
desktop rather than a fleet. HomelabHero ships no licence, so nothing of
its text is here; only the shape. Every skill separates what it may run
without asking (read-only) from what changes the machine (asks first,
prints the plan, then does it).
